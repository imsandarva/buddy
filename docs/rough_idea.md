Where this is now: overlay cursor + accessibility eyes + hands + type + the phone's own keys, driven by an **agent runner** that works the way described below — see the screen, think a little, act, see what changed, repeat until the goal is reached (`docs/agent.md`). The screen is read as a person reads it (rows, switches ON/OFF, lists that scroll, dialogs on top); the model keeps its own progress note, is told whether each step worked, asks before anything hard to undo, and reads answers off the screen. Voice is **audio-only** Gemini Live (`gemini-3.1-flash-live-preview`) — mic PCM in, voice PCM out; one quick tool itself, `run_goal` for anything longer. Typed asks go straight to the runner. We do not share the screen as Live video; Gemini’s video input is still ≤1 fps JPEGs, and AndroidWorld shows the text-only accessibility agent matches screenshot agents on Android, so SCREEN stays the accessibility tree. See `docs/agent.md`, `docs/live.md`, `docs/ask.md`, `docs/type.md`, and `docs/brain.md`.
